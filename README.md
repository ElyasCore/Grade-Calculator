Grade Calculator

A Java console application that collects a student's name and grades for Java, Math, Cybersecurity, and English, then calculates the student's overall performance.

The project focuses on input validation, arithmetic calculations, conditional grade classification, and determining the student's final pass or fail status.

Features
Enter student name
Enter grades for four subjects
Validate each grade between 0 and 100
Calculate the total grade
Calculate the average
Determine the letter grade from A to F
Determine pass or fail status
Ask the user to re-enter invalid grades
Concepts Practiced

Scanner · Variables · double · if/else · while · Arithmetic Operations · Comparisons · Logical Operators · Input Validation · Conditional Classification

Built as part of my Java learning journey to practice working with multiple inputs, calculations, validation, and multi-level conditional logic.
